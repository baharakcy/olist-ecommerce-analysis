# Olist-E-Commerce-analysis



Project Overview



This project analyzes the Olist Brazilian e-commerce dataset to explore sales performance, customer behavior, delivery performance, and customer satisfaction.



Tools \& Technologies



\* SQL

\* Python (Pandas, NumPy, Matplotlib, Seaborn)

\* Power BI



Project Structure



\* SQL/ — Data exploration and SQL queries

\* Python/ — Data cleaning, exploration, and analysis using Python

\* PowerBI/ — Interactive dashboard and visualizations



Key Analysis Areas



\* Sales and revenue analysis

\* Customer purchasing behavior

\* Delivery performance and delays

\* Customer review scores and satisfaction

\* Product category performance



Dataset



The dataset is provided by Olist and is available on Kaggle:



Brazilian E-Commerce Public Dataset by Olist



The raw dataset files are not included in this repository. Please download them from Kaggle to reproduce the analysis.



Project Goal



The goal of this project is to practice data analysis skills and turn raw e-commerce data into actionable business insights using SQL, Python, and Power BI.
